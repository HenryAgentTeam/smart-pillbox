# Contributing

Start with an issue describing the behavior to improve and how it can be verified. Keep changes small and document current limitations.

Use synthetic fixtures only. Do not commit personal health records, identity documents, signed agreements, credentials or private conversations. Contributions must be original or appropriately licensed, with third-party notices preserved.

By intentionally submitting a contribution to this repository, you offer it under BSD-3-Clause unless explicitly stated otherwise and agreed before acceptance. This does not replace any separate contributor agreement required by another project.

Tests should cover state transitions, duplicate events, reboot persistence, clock failure and the distinction between an opening and a user confirmation.
